## Бүтэц
- `index.html` - Вэб хуудасны үндсэн бүтэц (MN / EN хос хэлний дэмжлэгтэй)
- `styles.css` - Гүн хөх болон алтлаг хэв маягийн тансаг дизайн, responsive layout
- `script.js` - Бүтээгдэхүүний шүүлтүүр, үнийн санал авах цонх, хэл солих логик
- `assets/` - Байгууллагын лого болон нэрийн хуудас
